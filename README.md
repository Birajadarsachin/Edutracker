# YouTube Playlist Tracker

A simple web application that allows users to track and analyze YouTube playlists. Users can enter a playlist URL, and the app displays detailed statistics and video information.

---

## **Functionality**

- Enter a YouTube playlist URL.  
- Fetch playlist details using the YouTube Data API.  
- Display playlist stats:
  - Total number of videos
  - Total watch time (in hours and minutes)
  - Average video length
  - Longest & shortest video
  - Most viewed video
- Display all video titles in the playlist.
- Organized UI:
  - Playlist stats on the left
  - Current video in the center
  - Video list on the right

---

## **Tech Stack Used**

- **Frontend:** React  
- **Backend:** Node.js, Express  
- **API:** YouTube Data API v3  

---
